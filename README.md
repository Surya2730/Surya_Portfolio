# Surya Kumar T — Developer Portfolio

A futuristic, 3D-animated MERN stack personal portfolio website.

> Full documentation will be added in Phase 7.

## Tech Stack
- **Frontend:** React.js + Vite, CSS, React Three Fiber, Motion
- **Backend:** Node.js, Express.js, Mongoose
- **Database:** MongoDB Atlas (cloud only)
- **Deployment:** Vercel (frontend) + Render (backend)
